# Original speech data

Binary assets are permitted dependencies, but this scaffold does not copy them.
Once their formats are understood, load required BSNbn, skfs and snf1/snf2/snf3
files read-only from data/ or point ROZM_DATA_DIR at orig/ during development.

Keep original names and layout, including Sd2f capitalization on Linux. Local
binary files are ignored by Git. No EXE or LAME is part of the native Linux plan.
